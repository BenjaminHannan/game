# Open unknowns

Running ledger of unresolved design questions. Resolve a milestone's entries with the owner *before* building that milestone; move answered ones to the bottom with their decision.

## Open

- **Final name** — Metropolis is a working title.
- **Building art final pick** — build low-poly first (see below), then screenshot 2–3 palette/shape variants for the owner to choose from.

## Decided

- **First five minutes** — start on an empty map: lay roads, paint zones, watch the first buildings grow (default, owner told us to proceed; veto anytime — genre-classic opening, 2026-08-08).
- **Traffic model** — statistical flow per road edge plus lightweight visual vehicles (instanced meshes moving along edges). Per-vehicle agent pathfinding deferred to a later milestone (default: browser performance, 2026-08-08).
- **Art style** — low-poly flat-shaded, zone-conventional palette (default; final variant pick stays open above, 2026-08-08).
- **City scale target** — ~1–2k buildings at 60 fps via instancing (default, 2026-08-08).
- **Zoning feel** — painted zone cells along road frontage, CS-style drag painting (default, 2026-08-08).

- **Project identity** — city-builder inspired by Cities: Skylines II, not an idle game (owner, 2026-08-08). Original branding only; no trademarked naming.
- **Road MVP** — straight segments with node snapping first; curves later (roads research doc, 2026-08-08).
